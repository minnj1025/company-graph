# 평가 4판 — 검토에서 고친 것 (2026-10-12)

문항을 쓴 쪽과 따로 띄운 검토자가 묶음(원자료)만 보고 문항마다 다시 답해 본 뒤 정답과 견줬다. 같은 문항을 두 검토자가 따로 한 번씩 봤고 판정이 일치했다.
정답의 값을 고친 문항은 없다. 고친 것은 채점 기준과 skip 이유의 문구다. 문항별 기록은 `review/<id>.json`.

| 문항 | 고친 내용 |
|---|---|
| X3-06 | 질문은 금액이 바뀌었는지만 묻는데 must_include 가 금액 숫자까지 요구해 "바뀌지 않음"으로 줄이고, 숫자를 적은 답은 accept 로 옮김 |
| X3-08 | 질문이 묻지 않은 정정일과 사유를 must_include 에서 빼 accept 로 옮김 |
| X4-01 | 질문은 지분을 가진 상대만 묻는데 must_include 가 "지분 관계 없음"인 상대까지 요구해 accept 로 옮김 |
| X4-09 | must_not 의 "35.65%를 답하는 것"이 accept 와 부딪혀 "조회 시점의 지분율로 답하는 것"으로 좁힘 |
| X5-12 | must_not 의 한 항목이 표에 적힌 그대로의 값을 틀린 답으로 보게 돼 있어 고치고, 두 해의 표가 같다고 밝힌 답을 accept 에 더함 |
| X3-01 (skip) | skip 이유의 "정정이 한 번"을 원자료대로 두 번으로 고침 |
| X2-12 (skip) | skip 이유의 줄 수를 원자료대로 고침 |

채점할 때 이렇게 읽는다 (검토자가 남긴 것)
- X1-01: 출자 수량이 천 주 단위로 적힌 것으로 보인다는 추론이 정답에 있다. 단위를 단정하지 않고 수량이 다르게 적혀 있다고만 한 답도 맞는 것으로 본다
- X2-03: must_include 가 "합계 줄 또는 줄별 합 가운데 하나"라서, 합계 줄에 우선주가 섞인 것을 알아채지 못한 답도 통과한다. 쓴 뒤에는 고치지 않기로 했으므로 그대로 둔다
- X2-08: 재단의 이름 변경으로 본 답도 두 재단 이름은 언급해야 통과한다
