# 평가 5판 결과 — 1단계 (2026-10-16)

원인·평가를 묻는 24문항으로, 지시문에 "원인을 판단하지 않되 사실을 모아 답하라"는 구역을 더한 구성(B)을 지금 구성(A)과 견줬다. 기준은 결과 전에 [PLAN.md](PLAN.md)에 적었다. 모델은 둘 다 claude-haiku-5-5, 한 번씩 돌렸다. 채점은 두 답을 섞어 어느 구성의 것인지 가린 채로 했다(채점은 Claude).

| 구성 | 정답 | 부분 정답 | 답하지 못함 | 틀림 | 판단하지 않음과 알 수 없는 것을 밝힌 답 (W1~W4) |
|---|---|---|---|---|---|
| A 지금 | 14 | 8 | 0 | 2 | 14 / 20 |
| B 사실 모으기 | 22 | 2 | 0 | 0 | 20 / 20 |

종류별 정답 (A / B): 주가의 원인 4 / 5, 사업 평가 0 / 5, 사건의 영향 3 / 4, 비교 판단 3 / 4, 매매 판단 4 / 4

## 기준과 견주면

| 기준 | 결과 |
|---|---|
| W1~W4 정답이 A보다 5문항 이상 많을 것 | 10 → 18 (+8), 채움 |
| 틀림이 늘지 않고 원인 단정·전망이 B에서 0건일 것 | 틀림 2 → 0, 선을 넘은 답 0, 채움 |
| W5 매매 판단 4문항을 B도 모두 거절할 것 | 4 / 4, 채움 |
| 기존 문항이 나빠지지 않을 것 | 아직 재지 않음 (2단계) |

## 읽을 것

- **지금 구성도 거절만 하지는 않았다.** A도 24문항 모두 사실을 하나 이상 줬고 선을 넘은 답은 없었다. 차이는 범위를 밝히는지(14 → 20)와 사실을 빠짐없이 모으는지(모두 준 답 14 → 18)에서 났다
- **사업 평가(W2)에서 가장 크게 갈렸다 (0 → 5).** "전망 어때", "리스크가 뭐야"에 A는 사실을 늘어놓기만 하고 판단하지 않는다는 점이나 이 DB에 없는 것(실적, 업황)을 밝히지 않았다
- **A의 틀림 2건은 값을 잘못 읽은 것이다.** 자기자본 대비 비율을 지분율로 적었고(W1-01), 수출액을 제품 매출로 적었다(W2-03). B에서는 같은 문항이 맞았다
- **B가 나빠진 2문항**(W1-05, W3-01)은 정답에서 부분 정답으로, 사실 일부가 빠진 경우다
- 비용과 시간: B가 도구를 더 부르고(중앙값 5 → 6.5회) 답이 길어졌다(839 → 1,194자). 시간 12.2 → 17.0초, 비용 합계 0.110 → 0.134달러(단가는 추정)

- 문항 작성과 채점이 모두 Claude다

## 2단계: 운영에 올릴 구성의 회귀 확인 (2026-10-19)

올릴 구성(원인·평가 지시 켬 + 데이터 채움 + 기간 수익률 도구)으로 28문항만 다시 돌렸다. 비용을 줄이려고 2판 149문항 가운데 기록된 도구 호출을 지금 DB로 다시 실행해 결과가 바뀐 14문항만 골랐고(무료), 답하면 안 되는 질문 8문항과 5판 주가의 원인 6문항을 더했다. 같은 문항의 이전 답과 새 답을 섞어 가린 채 채점했다. 모델은 claude-haiku-5-5, 비용 약 0.135달러.

| 묶음 | 이전 답 (정답 / 부분 / 틀림) | 새 답 |
|---|---|---|
| 2판 22문항 (데이터 채움의 영향 14 + 답하면 안 되는 질문 8) | 16 / 3 / 3 | 21 / 1 / 0 |
| 5판 주가의 원인 6문항 | 5 / 1 / 0 | 6 / 0 / 0 |

나빠진 문항은 없고, 좋아진 문항은 T10-06, T11-05, T11-07(데이터 채움으로 우선주·0주·처분 줄이 보이게 된 문항), T11-06, T14-08, W1-05(기간 수익률을 쓴 문항)다. 답하면 안 되는 질문 8문항은 그대로 모두 거절했다. 새 수익률 도구는 28건 가운데 10건에서 쓰였다.

읽을 때: 앞의 14문항은 데이터를 채우기 전에 원인을 추적한 문항이 섞여 있어(T10-06, T11-05, T11-07) 이미 본 문항이다. 도구 결과가 그대로인 135문항은 다시 돌리지 않았으므로, 원인·평가 지시가 그 문항들에 영향을 주지 않았다고 단정할 수는 없다(사실을 묻는 질문이라 그 지시가 발동할 가능성은 낮다).

결론: 미리 정한 기준을 모두 채워 운영에 올린다.
