# 8판 결과 — 5% 대량보유 보고와 내부자 매매

문항과 정답은 Claude 하위 작업이 원자료 API 로 썼다(README). 답은 claude-haiku-5-5(사이트와 같은 모델)가 썼다.
채점: `python -m eval.v8.score` 가 카드 종류와 정답 값이 답에 나왔는지 세고, 나오지 않은 값과 없는 데이터 문항은 Claude(Opus)가 답을 읽어 가렸다.

## 0. 도구의 값 (모델 없이)

H01~H17 의 값을 get_major_holders, get_insider_trades 의 결과와 견주면 모두 같다. 견주다가 "새로 5% 이상" 표시가 '담보권 신규취득'(주식을 담보로 잡은 보고)에도 붙는 잘못을 찾아 고쳤다(H06, 에코프로의 이동채 보고).

공시 안의 검산(`python -m company_graph.holdings check`): 5% 보고 22,205건 중 비율이 0~100 밖인 것 0, 주식 수와 비율의 증감 방향이 반대인 것 796(3.6%, 발행주식 수가 바뀐 경우로 보인다).
최대주주 합계 + 그와 겹치지 않는 5% 보고자의 합이 100%를 넘는 회사는 처음 2,435곳 중 138곳이었다. 띄어쓰기를 무시한 이름, 앞부분이 같은 이름, 같은 기업집단으로 최대주주 쪽 보고를 알아보게 고친 뒤 61곳(2.5%)이 남았다.
남은 것은 공동보유자들이 각자 특별관계자를 합친 비율로 보고한 경우 등이라 더할 수 없고, 주주 분포 카드는 이 회사들을 한 막대로 합치지 않는다.
