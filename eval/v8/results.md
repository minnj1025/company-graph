# 8판 결과 — 5% 대량보유 보고와 내부자 매매

문항과 정답은 Claude 하위 작업이 원자료 API 로 썼다(README). 답은 claude-haiku-5-5(사이트와 같은 모델)가 썼다.
채점: `python -m eval.v8.score` 가 카드 종류와 정답 값이 답에 나왔는지 세고, 나오지 않은 값과 없는 데이터 문항은 Claude(Opus)가 답을 읽어 가렸다.

## 0. 도구의 값 (모델 없이)

H01~H17 의 값을 get_major_holders, get_insider_trades 의 결과와 견주면 모두 같다. 견주다가 "새로 5% 이상" 표시가 '담보권 신규취득'(주식을 담보로 잡은 보고)에도 붙는 잘못을 찾아 고쳤다(H06, 에코프로의 이동채 보고).

- 기계 채점은 62/66. H10 의 "늘린 보고 0건, 0주"는 답이 "늘린 보고는 없고"라고 적어 기계가 세지 못했고, 읽어 보면 맞다.
- 빠진 값 둘:
  - H02 "삼성물산 쪽이 삼성전자 지분 몇 %": 5% 보고(특별관계자 합산 19.69%)를 조회하지 않고, 사업보고서의 삼성물산 단독 지분(4.4%, 삼성전자 쪽 표 5.05%)을 적었다. 그 값 자체는 맞게 밝혔으므로 틀림이 아니라 빠짐으로 셌다.
  - H07: 김범수의 5% 보고(24.16%)를 적지 않고 사업보고서의 최대주주 합계(24.10%)를 적었다.
- 작은 잘못: H10 은 기간을 "2026-07-18~"이라고 적었다(도구는 07-19 부터). 값은 맞다.
- 카드를 더 띄운 문항: 한 주주의 비율이나 한 사람의 증감을 묻는 질문에 주주 분포 카드(H01, H03, H05, H06)와 내부자 매매 카드(H10, H12, H13), 없는 데이터 질문 H20 에 둘 다.
