# 평가 문항 8판 — 지분 보고와 내부자 매매를 맞게 답하는가

쓴 날짜: 2026-10-20

Agent가 두 가지 지분 공시를 쓸 수 있게 된다.

- 5% 대량보유 상황보고(OpenDART `majorstock.json`): 보고자별로 기준일 이전 마지막 보고의 보유비율(특별관계자 합산), 그리고 변동 이력. 마지막 보고 비율이 5% 아래면 "5% 미만으로 내려감".
- 임원·주요주주 특정증권등 소유상황보고(OpenDART `elestock.json`): 기간(기본은 기준일 이전 90일) 동안 보고자별 증감과 합계(늘린 보고 건수와 주식 수, 줄인 보고 건수와 주식 수, 순증감, 보고한 사람 수). 날짜는 보고 접수일(`rcept_dt`)이지 거래일이 아니다.

이 문항들은 세 가지를 잰다.

1. 값을 맞게 답하는가: 보고자별 마지막 보고를 쓰는가(옛 보고의 비율을 지금 값처럼 쓰지 않는가), 기간을 맞게 자르는가, 5% 보고와 임원 보고를 섞지 않는가.
2. 질문에 맞는 카드를 고르는가: 주주 분포(`holders`), 내부자 매매(`insiders`). 값 하나로 끝나는 질문에는 카드를 띄우지 않는가.
3. 없는 데이터를 없다고 하는가: 거래 단가와 금액, 실제 거래일, 장내·장외와 증여 같은 사유, 기관·외국인 수급, 공매도, 앞으로의 매매.

## 문항 수

| 종류 | 문항 | 기대 카드 | 값 항목 |
|---|---|---|---|
| 5% 보고 값 | 6 (H01~H06) | 없음 | 11 |
| 주주 분포 | 3 (H07~H09) | holders | 18 |
| 임원·주요주주 값 | 5 (H10~H14) | 없음 | 19 |
| 내부자 매매 흐름 | 3 (H15~H17) | insiders | 18 |
| 없는 데이터 | 3 (H18~H20) | 없음 | 0 (must_say 로 채점) |
| 합계 | 20 | 카드가 필요한 문항 6, 필요 없는 문항 14 | 66 |

문항별로 보는 것:

- H01 국민연금의 NAVER 비율: 세 번의 보고 중 마지막(9.49%)을 쓰는가.
- H02 삼성물산 쪽의 삼성전자 비율: 특별관계자 합산 값(19.69%), as_of 당일 접수 보고를 포함하는가.
- H03 SK하이닉스 캐피탈그룹: 보고자 이름이 바뀐 뒤 3.53%로 5% 미만이 된 것을 찾는가.
- H04 국민연금의 두산에너빌리티: 줄었는가(7.86% → 7.63%).
- H05 하나금융지주 최근 90일 5% 보고: Capital Research 한 건(6.88%, +1.33%p).
- H06 에코프로 올해 새 5% 주주: 신규 보고(삼성자산운용)와 데이터에 처음 나온 변동 보고(블랙록)를 구분하는가.
- H07 카카오, H08 신한지주, H09 대한항공: 5% 이상 주주와 비율.
- H10 카카오 임원 90일: 줄인 2건만 있음.
- H11 최태원의 SK하이닉스, H12 이재용의 삼성전자(as_of 당일 접수), H13 박순재의 알테오젠(주식 수는 늘고 비율은 줄었음): 한 사람의 증감과 보고 후 주식 수. 사유를 지어내지 않는가.
- H14 에코프로비엠 9월: 질문이 정한 기간으로 합계를 내는가.
- H15 삼성전자(보고 800건), H16 NAVER, H17 셀트리온: 90일 합계.
- H18 단가·금액, H19 사유·실제 거래일, H20 수급·공매도·전망: 없다고 하는가.

## 만든 방법

- 문항과 gold 는 Claude 서브에이전트가 기능 구현 전에, 기능 설명만 보고 DART 원자료 API 를 직접 불러 썼다. Agent의 지시문과 새 코드(`company_graph/agent.py`, `views.py`, 지분·내부자 모듈)는 읽지 않았다.
- 조회 시점(`as_of`)은 모두 2026-10-16. 기본 기간 90일은 2026-07-19~2026-10-16(양 끝 포함, `rcept_dt` 기준).
- 회사는 이름이 잘 알려진 후보 40개 중 로컬 DB 에 종목코드와 함께 있는 39개(같은 이름 행이 둘인 SK, 삼성물산을 포함해 41행. 엔씨소프트는 DB 에 없음)를 골라 두 API 를 회사마다 한 번씩 불렀다. `majorstock.json` 41회 + `elestock.json` 41회 = 82회. 무료 DART API 만 썼고 유료 API(Anthropic)는 쓰지 않았다. 그중 기간 안에 보고가 있고 이름이 잘 알려진 13개 회사를 문항에 썼다.
- 모든 값은 `rcept_dt` 가 2026-10-16 이하인 행에서만 계산했다. 받은 날(2026-10-20)에는 그 뒤 접수 4건(대한항공·삼성전자·KB금융 임원 보고, 에코프로비엠 5% 보고)이 있었고 모두 뺐다.
- 5% 값: 회사의 행을 (`rcept_dt`, `rcept_no`) 순으로 놓고 보고자(`repror`)마다 마지막 행의 `stkrt`(보유비율, 특별관계자 합산)를 썼다. 증감은 그 행의 `stkrt_irds`, `stkqy_irds`.
- 임원 합계: 기간 안의 모든 행에서 `sp_stock_lmp_irds_cnt` 가 양수인 행 수와 합(늘린 보고), 음수인 행 수와 절댓값 합(줄인 보고), 전체 합(순증감), 서로 다른 `repror` 수(보고한 사람). 같은 사람이 여러 번 보고하면 보고마다 센다. 증감 0인 행은 늘린 쪽에도 줄인 쪽에도 넣지 않았다(H15 의 1건).
- 각 값의 `rcept_no` 와 `formula` 에 쓴 행과 식을 적었다. H15(800행)만 `rcept_no` 를 비우고 필터 조건을 적었다.
- 이름 값은 원문 표기(`BlackRockFundAdvisors`)가 아니라 읽기 쉬운 표기로 적었다. 답에 '블랙록', 'BlackRock', 'Capital Research', '캐피탈 리서치'처럼 알아볼 수 있게 나오면 맞음으로 본다(`note` 에 적음).
- 질문은 실제 사용자 말투로 쓰고 "카드", "시각화", "그래프" 같은 말은 넣지 않았다. `company` 에는 DB 표시 이름을 적었다(사용자가 '네이버', '현대차'로 불러도 DB 에서는 NAVER, 현대자동차).
- `acceptable_kinds`: holders 문항은 ownership, insiders 문항은 timeline 과 returns(H17 은 holders 도). 값 질문과 없는 데이터 질문은 `expected_kinds` 가 비어 있어 카드를 띄우지 않아야 맞다.

## 채점 기준

- 값: 수는 같으면 맞음(비율은 ±0.01%p, 주식 수와 건수는 정확히). 이름 값은 답에 그 이름이 나오면 맞음. 다른 기간이나 다른 보고자의 값을 그 값처럼 적으면 틀림. 값이 없으면 빠짐.
- 카드: 6~7판과 같음(기대 kind 를 하나 이상 띄우고 나머지는 acceptable 안. expected_kinds 가 빈 문항은 카드를 띄우지 않아야 맞음).
- 없는 데이터 문항: must_say 를 모두 밝히고, 지어낸 숫자나 사유가 없으면 맞음.
- 채택 기준: 값 항목의 85% 이상 맞음, 틀린 값이 있는 문항 1개 이하, 카드가 필요한 문항의 80% 이상 맞음, 카드가 필요 없는 문항에 띄운 것 2개 이하, 없는 데이터 문항 모두 맞음.

## 파일

- `gold/H01.json` ~ `gold/H20.json`: 문항. 칸은 `id`, `question`, `as_of`, `company`, `expected_kinds`, `acceptable_kinds`, `values`(각 항목에 `label`, `value`, `unit`(`%`, `주`, `건`, `명`, `이름`), `rcept_no`, `formula`), `must_say`, `note`.
- `README.md`: 이 문서.

## 만들면서 알게 된 것

- API 는 회사마다 최근 약 2년치(가장 이른 접수일 2024-10-22)만 돌려준다. 그 전에 마지막으로 보고하고 그 뒤 변동이 없는 주주는 데이터에 없다. 예: 삼성전자 5% 보고는 삼성물산(대표보고자) 한 곳뿐이고 국민연금은 없다. 카카오뱅크는 국민연금 6.01% 한 건뿐이라 카카오·한국투자 쪽이 빠진다. SK하이닉스에도 국민연금이 없다. 이재용의 삼성전자 임원 보고도 2026-10-16 한 건뿐이다. 그래서 '5% 이상 주주 전체'를 묻는 문항은 데이터가 온전해 보이는 회사(카카오, 신한지주, 대한항공)로 골랐다.
- 보고자 이름: 영문 기관명은 공백 없이 붙어 있다(`BlackRockFundAdvisors`, `CapitalResearchandManagementCompany`). 캐피탈그룹은 2025-10-14 에 대표보고자를 바꿔 `TheCapitalGroupCompanies,Inc.` 가 0.00% 폐지보고를 내고 같은 날 `CapitalResearchandManagementCompany` 가 새로 보고했다(SK하이닉스, KB금융, 하나금융지주). 이름으로만 묶으면 옛 이름이 0%로 '5% 미만으로 내려감'에 남는다.
- 같은 사람이 같은 날 두 번 보고: 삼성전자 2026-07-21 에 20명.
- 보고 건수가 매우 많은 회사: 삼성전자 임원 보고는 2024-10 이후 3,372건, 90일 기간 800건, 그중 2026-07-21 하루 742건(90일 동안 보고한 사람은 731명).
- 보고자가 회사인 임원·주요주주 보고: 에코프로(에코프로비엠의 10% 이상 주주), 국민연금공단(한미약품), 한리버인베스트먼트피티이엘티디(넷마블). 보고자 수에 사람과 회사가 섞인다.
- `rcept_dt` 와 `rcept_no` 앞 8자리가 다른 행이 82개 파일에서 31개 있다(예: 에코프로비엠 임원 보고 20261008000733 은 2026-10-12, 5% 보고 20260918000504 는 2026-09-21). 문항 기간 계산은 `rcept_dt` 로 했다.
- 한 보고의 주식 수 증감과 비율 증감이 반대인 경우: 카카오 막시모피티이엘티디(주식 +19,807,507, 비율 −3.88%p, 주식 분할), 삼성바이오로직스 국민연금(주식 −1,565,902, 비율 +0.20%p), 알테오젠 박순재(주식 +30%, 비율 −0.57%p).
- 같은 지분을 두 대표보고자가 따로 보고: 넷마블은 2026-10-16 에 방준혁 56.02%, CJ ENM 55.85%, 고려아연은 영풍 41.13%, 한국기업투자홀딩스 36.92% 를 각각 보고했다. 서로를 특별관계자로 넣은 것으로 보여 더하면 중복이다. 그래서 이 두 회사는 문항에 쓰지 않았다.
- 한미약품: 국민연금 5% 보고(2026-10-02)는 9.61%, 임원·주요주주 보고(2026-10-06)는 10.15% 로 두 보고가 다르다. 또 2026-09-29 국민연금 소유상황보고는 증감을 보유 전체(+1,286,142)로 적어 늘린 주식 수 합계를 크게 부풀린다. 그래서 이 회사도 문항에 쓰지 않았다.
- 직위 표기가 보고마다 다르고 줄바꿈이 들어 있다(카카오 황유지: 'Kanana서비스 \n성과리더' → '메이커스 성과리더').
- 증감이 0인 임원 보고가 있다(삼성전자 20260721000096).
- DB 에 이름이 같은 상장 행이 둘인 회사: SK(00144155 는 두 API 모두 데이터 없음, 00181712 가 지금의 SK), 삼성물산(00126229 는 데이터 없음, 00149655 가 지금의 삼성물산).
