# 평가 10판 두 번째 홀드아웃 — 회사 5곳

쓴 날짜: 2026-10-21

## 무엇인가

평가 10판의 보고서는 처음 10곳(`eval/v10/companies.json`, R01~R10)을 보며 고쳤고, 처음 보는 5곳(`eval/v10/holdout`, H1~H5)으로 한 번 쟀다. 그 뒤에도 보고서를 고쳤으므로 H1~H5 도 이제는 '본 회사'다. 고친 보고서를 정직하게 재려고 보고서가 한 번도 보지 않은 회사 5곳(G1~G5)을 새로 두었다.

- 회사 5곳의 선정, gold, 이 문서는 Claude 서브에이전트가 썼다. 이 서브에이전트는 보고서를 만드는 코드(`company_graph/report.py`, `report_facts.py`, `agent.py`, `views.py`, `verify.py`)와 지금까지 나온 보고서·채점 결과(`eval/v10/r1`, `r2`, `reports`, `results.md`, `grades.json`, `grading.md`, `eval/v10/holdout/reports`, `holdout/grades.json`, `holdout/grading.md`)를 읽지 않았고 보고서 생성기를 돌리지 않았다.
- 읽은 것은 `eval/v10/README.md`(채점 기준), `eval/v10/companies.json`, `eval/v10/holdout/companies.json`, `eval/v10/holdout/README.md`, gold 형식 예시(`gold/R07.json`, `holdout/gold/H5.json`)와 DART 호출 도우미 `company_graph/dart.py` 뿐이다.
- 유료 API(Anthropic)는 쓰지 않았다. 값은 무료 OpenDART API 원자료와 공시 원문(document.xml)에서 계산했다. 로컬 DB 는 후보를 고를 때만 썼다(`company`, 그리고 회사별 공급계약·지분 결정 공시가 몇 건인지 세는 데 `relation` 의 접수번호 수). DB 의 값은 gold 에 쓰지 않았다.

채점 기준, 허용 범위, 파일 칸은 `eval/v10/README.md` 와 같다. 조회 시점(as_of)도 모두 2026-10-16 이다.

## 만든 방법

- 후보: DB 에서 최근 1년 공급계약·지분 결정 관계가 많은 상장사를 세어(유가·코스닥) 업종이 겹치지 않게 8곳(위 5곳과 비에이치아이, 테라사이언스, 엔씨)을 골라 `list.json` 으로 공시 구성을 봤다. 테라사이언스는 상장폐지·회생 절차라 뺐고, 비에이치아이는 파두와 경우가 겹치고, 엔씨는 크래프톤(H3)과 업종이 겹쳐 뺐다.
- 회사마다 부른 API(`company_graph.dart._json`, 응답은 따로 저장해 다시 부르지 않음):
  - `company.json`, `fnlttSinglAcnt.json`(2026 11012·11013, 2025 11011·11012), `hyslrSttus.json`(2025 사업보고서, 2026 반기), `alotMatter.json`(2025 사업보고서, 2026 반기), `majorstock.json`, `elestock.json`
  - 결정 API 11종(`piicDecsn` … `tsstkAqTrctrCcDecsn`)을 `bgn_de=20240101`, `end_de=20261016` 으로, 지분·자산·영업 양수도 결정 6종을 `bgn_de=20251017` 로
  - `list.json` 을 corp_code 별로 `pblntf_ty=I`·`B`(2025-10-17~2026-10-16), `A`·`D`(2025-01-01 부터)
  - `document.xml`: 공급계약·정정·해지 원문 전부(G1 19건, G2 39건, G3 20건), 지분 취득·처분 결정과 정정 원문 전부(G1 6, G3 6, G4 15, G5 6), 배당·소각 결정, 전환사채·자기전환사채 매도결정과 정정 일부, 최대주주변경, 투자판단·파생상품손실·단기차입 등
- 모든 값은 접수번호 앞 8자리가 `20261016` 이하인 행에서만 계산했다. 최근 90일 내부자는 `elestock` 접수일 2026-07-19~2026-10-16 이다.
- 12월 결산 5곳 모두 최근 분기는 2026 반기보고서의 2분기(4~6월)다.
- 최대주주 값은 2025 사업보고서(2025-12-31)를 주 값으로, 2026 반기보고서(2026-06-30) 값을 `also_ok` 로 두었다. 최대주주가 바뀐 엔켐만 반기 값을 주 값으로 했다.
- 공급계약 건수는 '공시 접수일 기준'과 '계약일 기준'이 다를 때 둘 다 적고 어느 기준인지 밝히면 맞도록 `also_ok` 를 두었다(G1, G2).
- must_include 는 46개(G1 9, G2 9, G3 9, G4 10, G5 9)다.
- 무료 DART 호출은 215번이었다(JSON API 170, 원문 45). 읽은 원문은 약 170건인데 나머지는 저장소 캐시(`data/cache/dart_document`)에 이미 있었다.

## 만들면서 알게 된 것

- 수정계약 재공시: 한화에어로스페이스의 2025-12-22 '단일판매ㆍ공급계약체결'(정정 아님, 3조 2,048억 원)은 2022-08-26 폴란드 K9 계약의 수정계약을 다시 공시한 것이다. 보고서명만 보면 창 안의 가장 큰 새 계약처럼 보인다. 원문의 '계약(수주)일자'를 봐야 한다.
- 비공개 계약: 접수 때 금액·상대·계약명이 모두 '-'인 계약(한화에어로스페이스 2025-12-16)은 엿새 뒤 [기재정정]으로 내용이 밝혀졌다. 정정을 버리면 금액을 모르고, 정정을 새 계약으로 세면 두 번 센다. 스페인 K9 계약은 as_of 에도 금액 비공개다.
- 계약일과 접수일: 파두의 2025-10-17 접수 계약은 계약일이 2025-10-16 이라 창의 시작일 하루 전이다. 계약일 기준 19건, 접수 기준 20건.
- 같은 날 두 공시: 한화에어로스페이스 2026-06-16 에 한국항공우주 1차 취득의 완료 정정과 2차 취득 새 결정이 함께 접수됐다. 결정 때 금액은 '취득 한도'이고 완료 정정의 금액이 실제 값이다.
- 자회사 표시 없는 자회사 공시: LS 의 [기재정정]단일판매ㆍ공급계약체결 3건과 [기재정정]교환사채권발행결정 1건은 보고서명에 '(자회사의 주요경영사항)'이 없지만 원문 머리에 '자회사인 LS전선㈜의 주요경영사항신고'라고 적혀 있다. 보고서명만으로는 지주회사 자신의 공시인지 가릴 수 없다.
- 그룹 안 계약: LS 자회사의 공급계약 9건은 상대가 모두 자회사의 미국 법인이고, 한화에어로스페이스의 가장 큰 새 계약도 상대가 자회사다.
- 창 밖 결정의 정정: 파두 7회차 전환사채(2025-05-21 결의)의 2026-06-30 조건 정정, 엔켐 듀오콤 취득(2025-06-17 결의)의 정정 6건, 오리온 오리온수협 출자(2025-09-18 결의)의 정정 2건은 모두 창 안에 접수됐지만 새 결정이 아니다. 정정으로 결의일 자체가 바뀌는 경우도 있다(오리온 종속회사 리가켐바이오 투자 2026-06-25 → 07-15·16, 엔켐 16회차 전환사채 01-20 → 01-30).
- as_of 뒤 정정본: 결정 API 는 마지막 정정본 한 행만 준다. 엔켐 14회차 전환사채(2024-10-14 결의)의 행은 접수번호가 20261020000185 라 as_of 기준으로는 보이지 않는 것이 맞다.
- 재작성된 전년 값: 엔켐의 2026 반기보고서 `frmtrm_amount`(2025년 2분기 영업이익 +9억 원)와 2025 반기보고서 `thstrm_amount`(-27억 원)가 부호부터 다르다. 2026-03-26 2023·2024 사업보고서 정정이 있었다. 한화에어로스페이스도 8,614억 원과 8,645억 원으로 조금 다르다.
- 최대주주와 지분 크기: LS 의 최대주주 구자열은 1.90%로, 특수관계인 구자은(3.69%)·구동휘(3.04%)보다 적다. LS `hyslrSttus` 2025 행의 주식 수는 1,000배로 적혀 있어 비율만 믿을 수 있다.
- 5% 보고의 빈자리: LS 의 `majorstock` 에는 국민연금공단이 없지만 `elestock` 에 10% 이상 주주 13.45%로 나온다. 파두는 공동대표 사임 뒤 5% 보고가 남이현 17.73%와 이지효 8.90%로 나뉘었다.
- 주식스왑의 방향: 엔켐은 미국 자회사 지분 100%를 THE GROWHUB 에 넘기고 그 대가로 THE GROWHUB 신주를 받아 85% 이상을 갖는다. 양도결정(주요사항보고서)과 취득결정(거래소 공시)이 같은 거래의 두 면이다.
- 배당기준일: LS 와 오리온 모두 2025 결산배당 기준일이 2025-12-31 이 아니라 2026-03-31 이다.
- 연결과 별도의 방향: 오리온 2분기 연결 영업이익은 늘었지만 별도는 줄었다. 파두는 영업이익 흑자, 당기순손실(전환사채 파생상품 평가손실)이다.
