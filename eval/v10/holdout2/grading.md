## 셈 방법

- **항목 채움**: 9개 항목이 있고, 자료가 있는데 '없음'으로 비우지 않았으면 ○.
- **핵심 사실**: gold 의 must_include 마다 맞음·틀림·빠짐을 매겼다. `also` 값이 있으면 주 값과 also 값이 모두 맞아야 맞음이다. 하나라도 없으면 빠짐, 값이 다르거나 사실의 핵심을 거꾸로 쓰면 틀림이다.
- **틀린 사실**: 원문이나 조회 결과와 다른 수·이름·날짜·방향. 요약과 본문에 같은 잘못이 되풀이되면 1개다. 한 목록에서 같은 코드 문형이 여러 줄에 반복되어도 1개로 셌다. 경미한 것도 수에 넣었다.
- **근거 없는 사실**: 접수번호나 출처 없이 수치를 적은 글머리 수(요약 제외). 하위 글머리에 접수번호가 있거나 같은 보고서의 접수번호 달린 사실로 거슬러 갈 수 있으면 세지 않았다.
- **선을 넘은 문장**: 원인 단정, 전망, 매수·매도·목표가, 결정을 실행 결과처럼 쓴 문장, gold must_not 위반. 문장마다 셌다.

## 잘못의 유형

1. **자회사의 결정을 이 회사의 결정으로 쓰는 코드 문형** (G1, G3, G5): 목록 줄이 "X가 ~하기로 결정 — 자회사 일을 대신 공시"로 나와 주어가 공시 회사가 된다. 원문에 '종속회사의 주요경영사항'이나 자회사 이름이 있어도 그렇다.
   - G1 한화오션 처분(한화시스템), G3 6건(LS전선·엘에스엠앤엠), G5 리가켐바이오(PAN ORION) 에서 나왔다.
   - 틀린 사실 3, must_not 위반 2(G1, G5)가 여기서 나왔다.
2. **정정 사슬을 접어 건수를 줄이거나 다른 계약을 지움** (G1, G3, G4, G5): 정정 여러 건을 마지막 1건으로 접어 '정정 공시 N건'을 적게 셌다.
   - G3 옛 계약 정정 7 → 5, G4 듀오콤 6 → 1, G5 오리온수협 2 → 1.
   - G3 은 같은 날·같은 상대의 두 계약 정정이 한 사슬로 이어져 계약 하나(2,162억 원)가 사라졌다. 핵심 사실 틀림이 됐다.
   - G1 은 비공개 계약의 정정 1건이 DB 에 없다.
3. **상대 회사의 지주회사가 낸 공시를 '이 회사가 대신 공시'로 분류** (G1): SNT홀딩스·비츠로테크가 자기 자회사의 계약을 공시한 3건을 한화에어로스페이스의 대리 공시로 보고 두 번 셌다(33건, 실제 30건).
4. **창 밖 결정의 정정을 최근 1년의 결정으로 셈** (G2): 결정 API 가 마지막 정정본 한 행만 주어 2025-05 전환사채가 2026-06-30 결정처럼 보였다.
   - 코드 문장("같은 기간 자본 결정 1건")과 모델 요약이 둘 다 이를 썼다. must_not 위반 2.
   - 첫 홀드아웃 H3(ADK)과 같은 모양이다.
5. **재작성된 전년 값** (G4): 조회 결과가 처음 보고값(-27.3억 원)과 재작성 기준 증감('적자 전환')을 함께 줬고 모델이 그대로 옮겼다. 핵심 사실 틀림과 must_not 위반 1.
6. **날짜 표시** (G2, G3, G5): 정정된 계약 줄의 '공시'일이 마지막 정정 공시일이다. G5 는 정정 후 결의일 대신 공시일을 결의일로 적었다.
7. **모델의 옮김 실수** (G1, G3, G5):
   - 방향: 유동비율이 중앙값보다 '낮다'(G5 요약).
   - 칸 이름: 교환청구기간을 '청약 기간'(G3).
   - 수: '특수관계인 15명'(G3), '최대 지분 73.10%'(G1).
   - 원자료 오기를 그대로: API 의 1,000배 주식 수(G3).
8. **빠짐** (8개):
   - 전년 동기 영업이익(G3), 별도 영업이익(G5).
   - 거래소 공시 쪽 사실: 주식소각결정(G3, G5), 분기배당(G5).
   - 결정 API 에 없는 자기전환사채 매도결정(G4).
   - 최대주주 변경(G4), 정정 경과·기재정정 건수(G2), 종속회사 전환사채(G5).

틀린 사실 19개 가운데 13개가 '최근 1년의 계약과 결정' 항목에서 나왔다. 그중 12개는 코드가 쓴 목록이고, 1개(G2 전환사채)는 코드 문장과 모델 요약에 함께 나왔다. 선을 넘은 문장 5개 가운데 3개도 이 항목의 코드 문장이다.

## 잘못이 없던 곳

다섯 보고서 모두 틀린 사실이 없었던 항목은 다음과 같다.

- **사업 구성**: 제품 비중, 부문 매출, 내수·수출 비율, 생산능력.
- **내부자 매매**: 건수, 증감 주식 수, 보유 후 수량. 감소 보고를 매도로 단정하지도 않았다.
- **주가**: 수익률·시장 중앙값·차이. 가격·목표가·전망·원인 단정이 없었다.
- **이 DB로 알 수 없는 것**.

그 밖의 항목은 다음과 같다.

- 실적과 재무는 G4 전년 동기 한 문장만 틀렸다. 2분기 영업이익·매출 다섯 회사 모두 맞았고, 연결·별도 혼동도 없었다.
- 자본 변동과 주주 환원은 G3 '청약 기간'(경미) 하나뿐이다. 배당 값은 다섯 회사 모두 맞았다.
- 지배 구조에서 적은 최대주주·5% 보고 비율 값은 다섯 회사 모두 원문과 같았다(G4 는 최대주주 변경을 빠뜨림). 틀린 것은 주식 수·인원·'최대' 같은 곁가지였다.
