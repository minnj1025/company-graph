# 평가 10판 홀드아웃 — 회사 5곳

쓴 날짜: 2026-10-20

## 무엇인가

평가 10판의 보고서는 처음 10곳(`eval/v10/companies.json`, R01~R10)으로 두 번 채점하고 그 결과를 보며 고쳤다. 고친 보고서가 그 10곳에만 맞춰진 것인지 보려고, 보고서를 한 번도 보지 않은 회사 5곳을 따로 두었다.

- 회사 5곳의 선정, gold, 이 문서는 Claude 서브에이전트가 썼다. 이 서브에이전트는 보고서를 만드는 코드(`company_graph/report.py`, `company_graph/report_facts.py`, `agent.py`, `views.py`)와 지금까지 나온 보고서·채점 결과(`eval/v10/r1`, `eval/v10/r2`, `eval/v10/reports`, `eval/v10/results.md`)를 읽지 않았다.
- 읽은 것은 `eval/v10/README.md`(채점 기준), `eval/v10/companies.json`, gold 형식 예시(`gold/R01.json`, `R07.json`, `R08.json`)뿐이다.
- 유료 API(Anthropic)는 쓰지 않았다. 값은 무료 OpenDART API 원자료에서 계산했다.

채점 기준, 허용 범위, 파일 칸은 `eval/v10/README.md` 와 같다. 조회 시점(as_of)도 모두 2026-10-16 이다.

## 만든 방법

- 후보는 로컬 DB(`company` 표, `stock_code` 있음, `corp_cls` Y/K)에서 업종별로 찾았다. 7곳(위 5곳과 유한양행, 삼양식품)의 원자료를 받아 보고서 재료(공급계약, 5% 보고, 배당·자본 결정)가 고르게 있는 5곳을 남겼다.
- 회사마다 부른 API(`company_graph.dart._json`):
  - `company.json`, `fnlttSinglAcnt.json`(2025·2026, 11013·11012·11014·11011), `hyslrSttus.json`(2025 사업보고서, 2026 반기), `alotMatter.json`(2025 사업보고서), `majorstock.json`, `elestock.json`
  - 결정 API 11종(`piicDecsn`, `fricDecsn`, `pifricDecsn`, `crDecsn`, `cvbdIsDecsn`, `bdwtIsDecsn`, `exbdIsDecsn`, `tsstkAqDecsn`, `tsstkAqTrctrCnsDecsn`, `tsstkDpDecsn`, `tsstkAqTrctrCcDecsn`)을 `bgn_de=20240101`, `end_de=20261016` 으로, 지분·자산·영업 양수도 결정 6종을 `bgn_de=20251017` 로
  - `list.json` 을 corp_code 별로 `pblntf_ty=I`(거래소 공시), `B`(주요사항보고서)는 2025-10-17~2026-10-16, `A`(정기공시)는 2025-01-01 부터
  - `document.xml`: 대우건설 공급계약·정정·해지 52건, 영업정지, 주식소각결정(현대차 1, 크래프톤 3, 대우건설 2), 타법인 취득(현대차 2, 크래프톤 2), 투자조합 출자(크래프톤 2), 중재(한전 2), 유상증자(에코프로비엠 2), 배당결정 7, 크래프톤 5% 보고 1
- 모든 값은 접수번호 앞 8자리가 `20261016` 이하인 행에서만 계산했다. 최근 90일 내부자는 `elestock` 접수일 2026-07-19~2026-10-16 이다.
- 12월 결산 5곳 모두 최근 분기는 2026 반기보고서의 2분기(4~6월)다.
- 최대주주 값은 2025 사업보고서(2025-12-31)를 주 값으로, 2026 반기보고서(2026-06-30) 값을 `also_ok` 로 두었다.
- must_include 는 43개(H1 9, H2 8, H3 9, H4 8, H5 9)다.

## 만들면서 알게 된 것

- 같은 날 접수: 대우건설의 가장 큰 계약(상도15구역 1조 4,367억 원, 20261016800313)이 as_of 당일 접수다. 앞 8자리로 잘라 비교하지 않으면 빠진다. 반대로 에코프로비엠의 2026-10-19 5% 보고(47.38%)는 as_of 뒤라 쓰면 안 된다.
- 정정 공시: 대우건설의 기재정정 24건 중 22건은 계약일이 2012~2024 인 옛 계약(이라크 Al Faw, 나이지리아 Gbaran 등)의 정정이다. 크래프톤의 2026-02-27·06-30 '타법인주식및출자증권취득결정' 정정은 2025-06-24 결정(ADK, 7,104억 원)의 금액 조정일자만 바꾼 것이다.
- 결정 API 는 마지막 정정본만 준다(1판과 같음). 에코프로비엠 유상증자는 2026-10-13 최종 정정 행(8,861억 원)만 남고, 최초 결정(1조 2,000억 원)은 원문으로만 보인다.
- 거래소 공시는 결정 API 에 없다: 주식소각결정, 타법인 취득 자율공시, 투자판단관련주요경영사항, 소송, 영업정지 금액 해석은 모두 원문에서 읽었다.
- 5% 보고의 기준: 크래프톤 장병규 보고에는 공동보유자 IMAGE FRAME INVESTMENT(HK)(최대출자자 Tencent)가 들어 있다. 현대차 현대모비스, 에코프로비엠 에코프로 보고는 최대주주 '계'와 같은 집단이다. 대우건설은 `majorstock` 조회 결과가 없다(013).
- 소유보고 해석: 에코프로비엠의 2026-09-18 19건은 유상증자 신주인수권증서 배정분이다(임원 증가분이 보유 주식 × 0.0910905 와 맞음).
- 방향: 한전 중재는 자회사 한수원이 신청인, 한전이 상대방이다. 대우건설 공급계약은 모두 '공사수주'로 대우건설이 시공한다.
- 금액의 뜻: 대우건설 '영업정지금액'은 정지 대상 부문의 2024 매출액이다. 현대차 소각예정금액 7,891억 원은 전일 종가 기준이고 장부가 기준은 4,764억 원이다.
- 무료 DART 호출은 약 400번(회사 7곳 원자료 약 300, 원문 약 85)이었다.
