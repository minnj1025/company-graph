# 평가 10판 — 기업 분석 보고서

쓴 날짜: 2026-10-20

## 목적

회사 하나와 조회 시점(as_of)을 주면 시스템이 DB 에서 정해진 조회로 사실을 모으고, 모델(claude-haiku-5-5)이 아홉 항목의 보고서를 쓴다. 항목은 요약, 사업 구성, 실적과 재무, 지배 구조와 주주, 최근 1년의 계약과 결정, 자본 변동과 주주 환원, 내부자 매매, 주가, 이 DB로 알 수 없는 것이다. 사실마다 접수번호를 달고, 원인 판단·전망·매수/매도 의견을 쓰지 않고, 결정 공시는 실행 결과가 아님을 밝히고, 금액은 조·억 원으로 적어야 한다.

글 속의 수를 모은 사실과 코드로 대조해 걸린 항목을 한 번 다시 쓰게 하는 검산이 있다. 이 평가는 두 가지를 잰다.

1. 보고서가 그 회사의 핵심 사실을 맞는 값으로 담고, 틀린 값·근거 없는 수치·선을 넘은 문장이 없는가.
2. 검산을 켰을 때가 껐을 때보다 나은가(틀린 사실이 늘면 검산을 끈다).

## 만든 방법

- 회사 선정, gold, 이 문서는 Claude 서브에이전트가 기능 구현 전에 기능 설명만 보고 썼다. 보고서 코드(`company_graph/report.py`, `agent.py`, `views.py`)는 읽지 않았다. 유료 API(Anthropic)는 쓰지 않았다.
- 후보는 로컬 DB(`company`, `major_holding`, `financial` 표)에서 골랐다: 5% 보고자가 많은 회사, 2025 연간 기말이 12월이 아닌 회사(48곳), 재무 첫 해가 2025 이후인 회사(122곳). 값은 DB 가 아니라 DART 원자료에서 다시 받았다.
- 회사마다 무료 OpenDART API 를 직접 불렀다(`company_graph.dart._json`).
  - `company.json`(결산월), `list.json`(corp_code 별, 2025-10-17~2026-10-16 전체와 2025-01-01 부터 정기공시 `pblntf_ty=A`)
  - `fnlttSinglAcnt.json`(2025·2026, 보고서 코드 11013·11012·11014·11011). 분기·반기보고서의 `thstrm_amount` 는 석 달 값, `frmtrm_amount` 는 전년 같은 석 달
  - `hyslrSttus.json`(2025 사업보고서 11011, 비교용 2026 반기 11012), `alotMatter.json`(2025 사업보고서), `majorstock.json`, `elestock.json`
  - 결정 API 11종(`piicDecsn`, `fricDecsn`, `pifricDecsn`, `crDecsn`, `cvbdIsDecsn`, `bdwtIsDecsn`, `exbdIsDecsn`, `tsstkAqDecsn`, `tsstkAqTrctrCnsDecsn`, `tsstkDpDecsn`, `tsstkAqTrctrCcDecsn`)을 `bgn_de=20240101`, `end_de=20261016` 으로, 지분 취득·처분 결정(`otcprStkInvscrInhDecsn`, `otcprStkInvscrTrfDecsn`)을 `bgn_de=20251017` 로

## 채점 기준 (실행 전에 정함)

보고서마다 별도의 Claude 채점자가 보고서와 gold 를 읽고 채점한다. 채점자는 검산을 켰는지 모른다.

- 항목 채움: 9개 항목이 모두 있고, 자료가 있는 항목을 "없음"으로 비우지 않았는가 (항목마다 ○/×)
- 핵심 사실: must_include 가운데 맞는 값으로 들어간 수 (값이 다르면 틀림, 없으면 빠짐)
- 틀린 사실: 보고서의 수·이름 가운데 근거(조회 결과나 원문)와 다른 것의 수
- 근거 없는 사실: 접수번호나 출처 없이 적힌 수치 문장의 수
- 선을 넘은 문장: 원인 단정, 전망, 매수·매도·목표가, 결정을 실행 결과처럼 쓴 문장의 수, must_not 위반
- 채택 기준(검산 켬 기준): 10개 보고서 합계로 핵심 사실의 80% 이상 맞음, 틀린 사실이 있는 보고서 2개 이하, 선을 넘은 문장 0, 항목 채움 95% 이상. 검산 켬이 끔보다 틀린 사실이 많으면 검산을 끈다.

값 대조 메모(위 기준을 적용할 때의 허용 범위):

- 금액은 보고서가 조·억 원으로 적으므로 억 원 단위의 반올림·버림 차이는 맞음(1억 원 또는 0.5% 이내 중 큰 쪽). 100억 원 미만은 0.01억 원(100만 원) 안이면 맞음. 영업손실을 "영업손실 225억 원"으로 적든 "-225억 원"으로 적든 맞음.
- 지분율은 ±0.01%p, 직접 나눠 낸 비율(부채비율·유동비율)은 ±0.1%p, 주식 수·건수는 정확히(삼성중공업 공급계약 건수만 ±1).
- `also_ok` 가 있는 항목은 그 값을 시점(예: 2026 반기보고서, 2026-06-30)과 함께 적어도 맞음. 시점 없이 다른 보고서의 값을 섞으면 틀림.
- 한 항목에 값이 여럿이면(`also`) 주 값 `value` 와 `also` 값이 모두 맞아야 맞음. 케이티앤지 5% 항목만 다섯 보고자 가운데 넷 이상이면 맞음.
- `"없음"` 값(배당 없음, 전년 동기 없음 등)은 보고서가 그 사실을 밝히면 맞고, 수를 지어내면 틀린 사실이다.
- must_include 의 `section` 은 기대하는 항목이고, 다른 항목에 맞는 값이 있어도 맞음으로 센다.
- 주가 항목은 gold 가 없다(가격은 DART 가 아님). 주가 항목에서는 틀린 사실 대신 가격·목표가·전망이 나오는지만 본다.
