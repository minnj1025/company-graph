# 평가 10판 세 번째 홀드아웃 — 회사 5곳

쓴 날짜: 2026-10-28

## 무엇인가

평가 10판의 보고서는 처음 10곳(`eval/v10/companies.json`, R01~R10)을 보며 고쳤고, 처음 보는 5곳(H1~H5, `eval/v10/holdout`)과 다시 처음 보는 5곳(G1~G5, `eval/v10/holdout2`)으로 잰 뒤에도 고쳤다. 그래서 G1~G5 도 이제는 '본 회사'다. 고친 보고서를 정직하게 재려고 보고서가 한 번도 보지 않은 회사 5곳(K1~K5)을 새로 두었다.

- 회사 5곳의 선정, gold, 이 문서는 Claude 서브에이전트가 썼다. 이 서브에이전트는 보고서를 만드는 코드(`company_graph/report.py`, `report_facts.py`, `agent.py`, `views.py`, `verify.py`)와 지금까지 나온 보고서·채점 결과(`eval/v10/r1`, `r2`, `reports`, `results.md`, `grades.json`, `grading.md`, `eval/v10/holdout/reports`·`grades.json`·`grading.md`, `eval/v10/holdout2/reports`·`grades.json`·`grading.md`)를 읽지 않았고 보고서 생성기(`company_graph.report`, `eval.v10.run`)를 돌리지 않았다.
- 읽은 것은 `eval/v10/README.md`(채점 기준), `eval/v10/companies.json`, `eval/v10/holdout/companies.json`, `eval/v10/holdout2/companies.json`, `eval/v10/holdout2/README.md`, gold 형식 예시(`holdout2/gold/G1.json`, `G3.json`), DART 호출 도우미 `company_graph/dart.py`·`cache.py`, 표 정의 `company_graph/db.py` 뿐이다.
- 유료 API(Anthropic)는 쓰지 않았다. 값은 무료 OpenDART API 원자료와 공시 원문(document.xml)에서 계산했다. 로컬 DB 는 후보를 고를 때만 썼다(`company` 와, 회사별 최근 1년 공급계약·지분 결정 관계가 몇 건인지 세는 데 `relation` 의 접수번호 수). DB 의 값은 gold 에 쓰지 않았다.

채점 기준, 허용 범위, 파일 칸은 `eval/v10/README.md` 와 같다. 조회 시점(as_of)도 모두 2026-10-16 이다.

## 만든 방법

- 후보: DB 에서 최근 1년 공급계약·지분 결정 관계 접수번호가 많은 상장사(유가·코스닥)를 세어, 업종이 겹치지 않게 12곳(위 5곳과 플리토, 앱클론, 포스코퓨처엠, 효성, LG씨엔에스, 코오롱, 삼성E&A)의 `list.json`(pblntf_ty `B`·`I`, 2025-10-17~2026-10-16)으로 공시 구성을 봤다. 앱클론은 바이오가 겹치고, 포스코퓨처엠은 2차전지 소재(에코프로비엠·엔켐)와 겹치고, 효성·코오롱은 지주회사 경우가 LS(G3)와 비슷하고 정정이 너무 많고(코오롱 37건), 플리토·LG씨엔에스·삼성E&A 는 결정이 적어 뺐다.
- 회사마다 부른 API(`company_graph.dart._json`, 응답은 따로 저장해 다시 부르지 않음):
  - `company.json`, `list.json`(corp_code 별, 2025-01-01~2026-10-16 전체), `fnlttSinglAcnt.json`(2026 11012·11013, 2025 11011·11012), `hyslrSttus.json`·`alotMatter.json`(2025 사업보고서, 2026 반기), `majorstock.json`, `elestock.json`
  - 결정 API 11종(`piicDecsn` … `tsstkAqTrctrCcDecsn`)을 `bgn_de=20240101`, `end_de=20261016` 으로, 지분·자산·영업 양수도 결정 6종을 `bgn_de=20251017` 로
  - `document.xml`: 창 안 공급계약·정정·해지 원문 전부(K1 9, K2 22, K3 15, K4 28, K5 16), 지분 취득·처분·양수·양도 결정과 정정 원문 전부, 유상증자·자기주식·소각·배당·전환청구·교환청구·전환가액조정·사채취득·자회사 탈퇴·합병 등
  - 확인용으로 SK가스(corp_code 00144164)의 2026-03-20~04-10 거래소 공시 목록 1번
- 모든 값은 접수번호 앞 8자리가 `20261016` 이하인 행에서만 계산했다. 최근 90일 내부자는 `elestock` 접수일 2026-07-19~2026-10-16 이다.
- 12월 결산 5곳 모두 최근 분기는 2026 반기보고서의 2분기(4~6월)다.
- 최대주주 값은 2025 사업보고서(2025-12-31)를 주 값으로, 2026 반기보고서(2026-06-30) 값을 `also_ok` 로 두었다. `hyslrSttus` 는 기초(`bsis_*`)와 기말(`trmend_*`) 값이 다른 회사가 있어(SK디스커버리 40.72 → 41.69, 선익시스템 47.46 → 47.13, 씨에스윈드 합계 41.40 → 39.80) 기말 값을 썼다.
- 공급계약 건수는 '계약일 기준'과 '접수 기준'이 다를 때(K2) 둘 다 적고 어느 기준인지 밝히면 맞도록 `also_ok` 를 두었다. 정정 건수와 정정된 계약 수를 따로 셌다.
- must_include 는 50개(K1 11, K2 10, K3 10, K4 9, K5 10)다.
- 무료 DART 호출은 217번이었다(JSON API 178, 원문 39). 읽은 원문은 약 150건인데 나머지는 저장소 캐시(`data/cache/dart_document`)에 이미 있었다.

## 만들면서 알게 된 것

- 부모·자식 중복 공시: SK디스커버리가 '자회사의 주요경영사항'으로 낸 SK가스 석유제품 저장위탁계약(3,740억 원, 20260324801343)은 SK가스가 같은 날 자기 이름으로도 냈다(20260324801309). 회사별로 계약을 모으면 그룹 단위에서는 두 번 잡힌다.
- 같은 거래의 두 공시: 삼성바이오로직스의 PolyPeptide 인수는 모회사의 '타법인주식및출자증권양수결정'(주요사항보고서, 2026-07-17 결의)과 공개매수 주체인 종속회사 Samsung Peptide AG 의 '취득결정(종속회사의주요경영사항)'(2026-08-31)으로 두 번 나온다. 금액(2조 7,062억 원)도 같다. HGS 인수도 종속회사의 취득결정과 그 자금을 대는 모회사의 증자 참여(5,249억 원)가 같은 돈이다.
- 결정 API 에 안 나오는 결정: 지주회사가 대신 낸 자회사의 주요사항보고서(SK가스의 울산GPS 양도 1조 2,242억 원)는 SK디스커버리 corp_code 로 `otcprStkInvscrTrfDecsn` 을 불러도 013 이다. 거래소 공시인 '타법인주식및출자증권처분결정'(SK이터닉스, SK디앤디, 두산에너빌리티 베트남 법인)도 결정 API 에는 없다.
- 창 밖 결정의 정정: SK디스커버리 SK디앤디 처분(2025-09-30 결의, 2025-10-01 공시)은 창 시작(2025-10-17) 직전의 결정인데 정정 4건(처분일 연기, 종결합의, 문구 삭제, 거래종결)이 창 안에 있다. 두산에너빌리티 베트남 법인 처분(2025-08-20)도 창 안에는 거래종결 정정만 있다. 자회사 쪽은 2020·2022·2024 결정의 정정(출자금액 확정, 계약해제)이 창 안에 여러 건이다. 자본 결정 쪽에서는 창 밖 결정의 정정이 창 안에 접수된 경우를 이번 5곳에서 찾지 못했다(선익시스템의 2024 전환사채·교환사채는 정정이 아니라 전환청구·리픽싱·사채취득 같은 후속 공시다).
- 장부가와 실제 가격: SK디스커버리의 SK디앤디 처분 공시 금액 1,098.7억 원은 장부가액이고 실제 처분가액은 742.3억 원이라고 원문에 적혀 있다(실제가가 장부가보다 작아 장부가를 기재).
- 재작성된 전년 동기 값: 삼성바이오로직스 2026 반기보고서의 2025년 2분기 연결 매출은 1조 142억 원으로 2025 반기보고서 값(1조 2,899억 원)보다 2,757억 원 작다. 분할된 바이오에피스 몫이 빠진 값이고, 재작성 값은 2025 반기보고서의 별도 매출과 정확히 같다. 영업이익 차이는 16억 원(0.3%)뿐이라 허용 범위 안이지만 매출로 비교하면 증가율이 2.4%와 30.2%로 갈린다. SK디스커버리는 영업이익은 그대로인데 당기순이익의 전년 동기 값만 220억 → 281억 원으로 바뀌었다.
- 늦게 공시된 계약: 삼성바이오로직스 2026-03-13 공시 계약의 계약일은 2025-08-11 이다(체결 때는 공시 기준 미달, 최소구매물량 확정 뒤 공시). 접수일만 보면 창 안 계약으로 센다.
- 유보 해제로 드러나는 옛 금액: 선익시스템의 2026-01-30 정정은 2024-06 계약 금액 3,797.8억 원을 처음 공개했고, 씨에스윈드의 2025-12-30 정정 2건은 2024-11 Atlantic Shores 계약(5,658억 원)과 2025-02 해지를 함께 공개했다. 둘 다 창 안 어떤 새 계약보다 크다.
- '공시 기준 강화' 하향 정정: 선익시스템은 2025-12-30 부터 미수령 잔금(대개 10%)을 뺀 금액으로 계약금액을 다시 적었다(가장 큰 새 계약 410.4억 → 369.4억 원). 계약서 총액은 그대로이고, 잔금을 받으면 원래 금액으로 되돌린다(SFC 계약 71.8 → 64.6 → 71.8억 원).
- 정정이 끝을 알리는 경우: SK디스커버리(에스케이플라즈마)의 2022 AKSIA 계약은 '신규 계약 체결에 따른 기존 계약 종료'로 종료일을 당긴 기재정정(2026-04-03)이고 해지 공시가 아니다. 씨에스윈드 안마해상풍력 계약은 '계약 중단'으로 종료일을 미정으로 바꿨을 뿐 해지 공시는 없다. 두산에너빌리티 카자흐 계약은 증액분 배분 협의 중이라 금액을 '-'로 바꿨다.
- 계약 상대: 두산에너빌리티의 가장 큰 계약(체코 두코바니 NSSS 4조 9,290억 원)과 터빈(7,111억 원)의 상대는 체코 발주처가 아니라 한국수력원자력이다. SK가스 계약 상대 SK온은 계열회사다. 삼성바이오로직스 계약 상대는 모두 '유럽 소재 제약사'처럼 지역만 적힌다.
