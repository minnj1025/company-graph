## 채택 기준

README 의 채택 기준은 검산 켬 보고서에 대한 것이다. 이번 2차 보고서는 모두 `-off`(검산 끔, json 의 verified=false)이므로 같은 기준을 이 10개에 대 본 결과다.

| 기준 | 결과 | 통과 |
|---|---|---|
| 핵심 사실 80% 이상 맞음 | 73/86 = 84.9% | 예 |
| 틀린 사실이 있는 보고서 2개 이하 | 7개 (반올림만 걸린 것 빼면 6개) | 아니오 |
| 선을 넘은 문장 0 | 5 | 아니오 |
| 항목 채움 95% 이상 | 90/90 = 100.0% | 예 |

반올림만 걸린 것을 빼도 틀린 사실이 있는 보고서는 6개라 기준(2개 이하)에 못 미친다. 선을 넘은 문장 5개는 모두 gold 의 must_not 에 적힌 경우다(LG 자회사 공시 2, 현대약품 연결 표기 1, 삼성중공업 정정 셈 1, STX 옛 최대주주 1).

9. 반올림 (R04, R06, R10): 조회 도구가 0.1억 원·0.1%p 로 준 값을 옮겨 README 허용폭을 넘었다. 핵심 사실 틀림 5개 가운데 3개가 이것이다.
