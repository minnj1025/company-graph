# 평가 10판 채점 결과

채점자는 Claude 서브에이전트다. 채점자는 어느 보고서가 검산을 켠 쪽인지 몰랐다. `company_graph/report.py`, `eval/v10/reports/`, 가림 열쇠는 열지 않았다. 유료 API 는 쓰지 않았다.

- 사실 대조: 보고서가 쓴 것과 같은 로컬 DB 를 `company_graph.agent_tools.call` 로 조회했다(as_of 2026-10-16). 조회한 도구는 find_company, get_financials(연결·별도), get_relations(equity in/out, supply_contract, supply_termination, stake_acquisition, stake_disposal), get_major_holders, get_insider_trades, get_capital_events, get_dividends, get_products, get_business, get_price_history 다.
- 회사별 정답: `gold/R01~R10.json` 의 must_include 와 must_not.
- 항목마다 판단 근거는 `grades.json` 에 있다.

## 핵심 사실이 빠진 이유 (37건)

- 전년 동기 값(12건): 삼성전자, LG, KB금융, 현대약품, 삼성중공업, 케이티앤지에서 양쪽 보고서 모두 증감률(예: +92.49%)만 쓰고, gold 가 요구한 전년 동기 금액(예: 2,769억 원)은 쓰지 않았다.
- 배당 없음(10건): HLB, 프리티, 삼성중공업, STX, 삼성에피스홀딩스의 양쪽 보고서가 '배당 표가 없다'나 '공시된 것이 없거나 이 DB가 모으지 않았다'라고만 썼다. 배당을 하지 않았다는 사실은 밝히지 않았다. 조회 도구가 '배당 표가 없습니다'라고만 돌려주니 데이터 쪽 한계에 가깝다.
- 삼성중공업 계약 3건(29건, 4조 3,301억 원, 6,722억 원)은 두 보고서 모두 빠졌다. 공급계약 조회가 50건에서 잘려 2026-10-02 계약은 보이지 않았고, 4조 3,301억 원 해양설비 계약도 쓰지 않았다.
- 그 밖: also 값 누락(전환가액 3건), 현대약품의 신풍제약 주식 양수결정(2건, DB 에 없음), 프리티 B04 의 감자·증자 세부, KB금융 B07 의 04-23 취득결정 단독 값, 삼성에피스 B06 의 삼성물산 5% 보고 값.

## 근거 없는 사실 (66건)

- 가장 흔한 것은 '시장 중앙값' 문장(14개 보고서)이다. 이 문장을 접수번호가 있는 줄과 따로 쓰고 출처를 달지 않았다.
- 주가 항목에서 한국거래소·KRX 출처를 적지 않은 보고서가 7개다(B05, B06, B08, B09, B10, B12, B14). 이런 보고서는 수익률 줄마다 하나로 셌다.
- 이 밖에 내부자 매매의 합계 줄, 배당 연도별 줄처럼 같은 묶음의 다른 줄에만 접수번호를 단 경우가 있다.

## 선을 넘은 문장 (3건)

- B07(KB금융): '자기주식 취득 결정은 2026년에 약 3조 원 규모'와 '2026년 결정 규모는 약 3조 원'. 신탁계약과 직접 취득을 한 금액으로 합쳤고(must_not), 합계도 틀렸다.
- B04(프리티): 요약에서 '최대주주 밀레니엄홀딩스 3.86%… 입니다'라고 시점 없이 씀(must_not, 2026 반기에는 KS인더스트리가 최대주주).
- 원인 단정, 전망, 매수·매도·목표가, 결정을 실행 결과처럼 쓴 문장은 20개 모두에서 찾지 못했다.

## 그 밖에 본 것

- 검산 메모가 본문에 남은 보고서가 4개다: B01(실적), B02(실적), B04(실적), B14(주가). '이전 답에서 … 전체를 다시 쓰면 아래와 같습니다', '수정 없이 항목을 다시 작성합니다' 같은 문장이 독자에게 그대로 보인다. 틀린 사실로 세지는 않았다. 숫자가 든 메모 문단은 근거 없는 사실 1건으로 셌다.
- 주가 항목에서 '동종 중앙값이 조회 결과에 없다'고 했지만 실제로는 있는 경우가 B16, B17, B02 에 있다. B11 은 3개월 동종 비교를 거꾸로 썼다. README 대로 주가 항목은 틀린 사실로 세지 않고 notes 에만 적었다.
- 양쪽 보고서에 똑같이 붙는 카드 가운데, LG 와 STX 의 '주주 분포' 카드는 최대주주 쪽 합계와 5% 보고(LG 연암학원 43.39%, STX 옛 보고 38.67%·7.98%)를 나란히 놓아 합이 100%를 넘는다. 카드는 모델 문장이 아니라서 선을 넘은 문장으로 세지 않았다.
- must_not 가운데 자주 걸릴 만한 것(부채비율이 음수인 STX 의 부채비율, KB금융 매출액·유동비율 지어내기, 별도·연결 섞기, 출자전환을 장내 매매로 쓰기, 감자를 끝난 일로 쓰기)은 모든 보고서가 지켰다.

## 채점자가 판단한 경계

1. 항목 채움 ×6: B02·B11(STX), B04·B19(프리티), B07·B08(KB금융)은 '최근 1년의 계약과 결정'을 '공시된 것이 없거나 이 DB가 모으지 않았다'로 비웠다. 실제로는 1년 안에 자기주식·증자·감자·전환사채 결정이 있다. 시스템은 이런 결정을 '자본 변동' 항목에 싣도록 짜여 있지만, 항목 이름이 '결정'을 포함하고 gold 도 KB금융·프리티의 결정을 이 항목에 두었으므로 ×로 셌다. 공급계약·지분 결정과 자본 결정이 모두 없는 회사(삼성에피스)는 ○다. 이 판단을 빼면 항목 채움은 180/180 이다.
2. '배당 표가 없다'는 '배당 없음'을 밝힌 것으로 보지 않았다(빠짐).
3. `also` 값이 빠지면(예: 전환가액) README 의 '모두 맞아야 맞음'에 따라 빠짐으로 셌다.
4. 프리티 2분기 영업손실을 양쪽 모두 '13.1억 원'으로 썼다(gold 13.12억 원). README 의 '100억 원 미만은 0.01억 원 이내'를 글자 그대로 적용하면 틀림이다. 하지만 조회 도구가 0.1억 단위로 준 값을 그대로 옮긴 것이라 맞음으로 셌다. 양쪽 보고서에 같으므로 켬·끔 비교에는 영향이 없다.
5. 프리티 2026-10-14 유상증자 1,600,004주는 as_of 전 접수번호(20261014000185)로 DB 에 있다. 그래서 must_not(20261020000255 값 사용)으로 보지 않았다.
