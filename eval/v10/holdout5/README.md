# 평가 10판 다섯 번째 홀드아웃 — 회사 5곳

쓴 날짜: 2026-11-05

## 무엇인가

평가 10판의 보고서는 처음 10곳(`eval/v10/companies.json`, R01~R10)을 보며 고쳤고, 처음 보는 5곳을 네 번(H1~H5 `eval/v10/holdout`, G1~G5 `holdout2`, K1~K5 `holdout3`, M1~M5 `holdout4`) 잰 뒤에도 매번 고쳤다. 그래서 M1~M5 도 이제는 '본 회사'다. 고친 보고서를 정직하게 재려고 보고서가 한 번도 보지 않은 회사 5곳(N1~N5)을 새로 두었다.

- 회사 5곳의 선정, gold, 이 문서는 Claude 서브에이전트가 썼다. 이 서브에이전트는 보고서를 만드는 코드(`company_graph/report.py`, `report_facts.py`, `agent.py`, `agent_tools.py`, `views.py`, `verify.py`)와 지금까지 나온 보고서·채점 결과(`eval/v10/r1`, `r2`, `reports`, `results.md`, 그리고 `eval/v10` 과 `holdout`~`holdout4` 의 `grades.json`·`grading.md`·`reports`)를 읽지 않았고 보고서 생성기(`company_graph.report`, `eval.v10.run`)를 돌리지 않았다.
- 읽은 것은 `eval/v10/README.md`(채점 기준), `holdout4/README.md`, gold 형식 예시(`holdout4/gold/M1.json`, `M4.json`), `eval/v10`·`holdout`~`holdout4` 의 `companies.json`, DART 호출 도우미 `company_graph/dart.py`·`cache.py`, 표 정의 `company_graph/db.py` 앞부분, 설정 `company_graph/config.py`(인증키 값은 보지 않음)뿐이다.
- 유료 API(Anthropic)는 쓰지 않았다. 값은 무료 OpenDART API 원자료와 공시 원문(document.xml)에서 계산했다. 로컬 DB 는 후보 회사의 corp_code·시장 구분을 찾는 데만 썼다(`company` 표). DB 의 값은 gold 에 쓰지 않았다.

채점 기준, 허용 범위, 파일 칸은 `eval/v10/README.md` 와 같다. 조회 시점(as_of)도 모두 2026-10-16, 최근 1년 창은 2025-10-17~2026-10-16 이다.

## 만든 방법

- 후보: 30곳과 겹치지 않는 상장사 11곳(삼성물산, 고려아연, 피엔티, 한미반도체, NAVER, 케이티, 한화, 현대건설, 원익IPS, 에스티아이, LIG디펜스앤에어로스페이스)의 `list.json`(pblntf_ty `B`·`I`, 2025-10-17~2026-10-16)으로 공시 구성을 봤다. 한미반도체·원익IPS·에스티아이는 결정 공시가 적고, 케이티는 자기주식·배당에 몰리고, 현대건설은 건설로 H5·M4 와 겹쳐 뺐다. 한화(인적분할, 우선주 둘)는 지주회사로 R02·G3·M1 과 겹쳐 남기지 않았다.

## 만들면서 알게 된 것

- 새 공시인데 옛 계약: 삼성물산의 P5(2조 8,932.2억 원)·P4 Ph2(1조 3,791.7억 원) 공시는 정정이 아니라 '단일판매ㆍ공급계약체결'로 나오지만, 원문은 2022-12(414억 원)·2023-07(100억 원)에 맺은 최초 계약의 변경계약이라 적는다. 계약기간 시작일도 2022·2023 년이다. 공시 기준을 넘는 순간 처음 공시된 것이다.
- 정정이 대부분 옛 계약: 삼성물산 정정 22건 중 20건, 피엔티 10건 모두, LIG 11건 중 10건이 창 밖 계약의 것이다. 삼성물산 새울원자력 3,4호기(2020-09 계약)는 창 안에서만 네 번 증액됐다. 천안 C-PJT 는 원 공시가 2025-10-13 로 창이 열리기 나흘 전이다.
- 정정 금액이 줄어도 계약은 그대로: 피엔티 북미 계약은 1,174.9억 → 1,130.7억 → 1,067.5억 원으로 정정됐지만 원문은 '실제 계약금액엔 변동이 없으며 차액은 향후 수취할 예정'이라 적는다(달러 계약을 그때그때 환율로 환산).
- 같은 날 소각과 감자: 삼성물산은 2026-01-28 자기주식 7,807,563주를 상법 제343조 소각(자본금 그대로)으로, 2015 합병 반대주주에게서 산 1,400주는 주요사항보고서 '감자결정'(자본금 감소, 채권자 이의절차)으로 따로 냈다. 결정 API 는 감자만 `crDecsn` 으로 준다.
- 환율 두 기준의 같은 증자: 고려아연 유상증자는 USD 19.4억으로 확정됐고, 원화는 이사회 직전 영업일 환율(2조 8,508.3억 원)과 납입일 환율(2조 8,335.6억 원) 두 값이 공시와 정정에 함께 나온다. 발행결과 공시도 정정으로 바뀌었다.
- 재작성 정정: 고려아연은 2026-08-13 하루에 2022 사업보고서부터 2026 1분기보고서까지 14건을 정정했다(증선위 감리 조치). `fnlttSinglAcnt` 의 2025 반기·2025 사업보고서 값도 정정본에서 온다. 2025 영업이익·순이익은 그대로고 자본·영업권과 2024 순이익이 바뀌었다.
- 전년 동기 값이 다른 경우: LIG 2026 반기보고서의 2025년 2분기 연결 영업이익(815.9억 원)은 2025 반기보고서(775.8억 원)와 다르고 1분기도 다르지만 상반기 합은 같다. 보고서에서 이유를 찾지 못했다. 별도와 매출은 같다.
- as_of 뒤 정정만 남은 결정 API: NAVER `piicDecsn` 의 유일한 행은 2026-11-03 정정본(6,558,435주)이다. as_of 기준 값은 2026-07-27 원 공시(잠정 7,241,564주)뿐이고 납입 전이다.
- 창 밖 결정의 창 안 정정: NAVER 왈라팝 인수(2025-08-05), 자기주식처분 정정 4건(2022~2023 주식매수선택권), 고려아연 소각(2025-05-08 결정)의 3차 소각일 정정, 피엔티·LIG 의 옛 계약 정정.
- 같은 돈의 여러 공시: NAVER 의 스페인 종속회사 대여(금전대여결정), 출자전환(타법인주식취득결정), 종속회사 유상증자결정은 같은 약 9,740억 원이다. 고려아연의 유상증자 대금은 그대로 미국 지주회사 출자로 들어간다.
- 종속회사 대신 공시: 삼성물산의 PolyPeptide 인수·삼성바이오로직스 유상증자, NAVER 의 네이버파이낸셜–두나무 주식교환·NW HOLDINGS 증자, 고려아연의 호주 손자회사 증자는 모두 '종속회사의 주요경영사항'이다.
- 공시 유보: LIG 해궁 수출은 계약명·금액·상대를 비운 공시 다음 날 정정으로 공개됐고, 피엔티 옛 계약 대부분은 계약상대가 계속 유보다.
- 5% 보고 해석: 피엔티 김준섭의 2025-12-22 보고는 직전 보고가 2018-05-08 이라 비율이 -9.84%p 로 나오지만 주식은 늘었다. 고려아연 한국기업투자홀딩스 보고는 영풍·와이피씨를 공동보유자로 넣은 같은 묶음이다. NAVER 는 사업보고서 최대주주가 국민연금공단이다.
