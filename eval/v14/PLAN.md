# 평가 14판 — Agent가 직접 짜는 분석 페이지 (save_page)

쓴 날짜: 2026-11-18 (실행 전)

## 왜

채팅 답을 그대로 페이지로 남기는 단추(90ae743)는 Agent를 부르지 않는다. 사용자가 "○○를 한 페이지로 정리해 줘"라고 하면 Agent가 직접 카드와 글을 골라 페이지를 짜게 하려 한다. 페이지는 주소로 남과 나눌 수 있으므로, 글이 틀리거나 매매 권유가 들어가면 채팅 답보다 문제가 크다. 그래서 기본으로 켜기 전에 잰다.

## 바꾼 것 (ASK_PAGES=1 일 때만, 기본은 끔)

- 도구 `save_page(title, blocks)` (company_graph/pages.py). 블록은 글(600자 안) 또는 카드(종류와 대상). 카드의 숫자는 서버가 DB에서 채운다.
- 도구 안의 검사(돈이 들지 않음): 카드마다 실제로 한 번 만들어 보고 실패하면 거절, 글의 접수번호가 이번 조회 결과에 없으면 거절, 금지 표현(wording.py)이 있으면 거절, 조회 결과에서 확인되지 않는 숫자(verify.py)는 한 번 돌려보내고 두 번째에는 받되 `unverified` 로 적는다. 거절되면 Agent가 고쳐 다시 부른다.
- 규칙 `make-page` (skills/make-page/SKILL.md): 분명히 요청했을 때만 부르고, 조회를 먼저 하고, 카드 2~6장, 글은 짧게, 매매 판단·전망 페이지는 만들지 않는다.
- 끄면 지시문과 도구 목록은 그 전과 글자까지 같다(tests/test_pages.py).
- 사이트에서는 답이 끝나면 서버가 설계도를 저장하고 주소를 준다. 평가는 서버를 거치지 않으므로 저장하지 않고 설계도(page_spec)만 본다.

## 문항

`questions.json`. 모두 Claude가 이 판을 위해 썼다. 조회 시점 2026-11-18(로컬 DB).
- 페이지 요청 15문항(P01~P15): 한 회사의 지분·실적·주주·자본·배당·공급계약, 두 회사 비교·연결. 문항마다 요청한 항목(asks)을 적어 두었다.
- 페이지로 만들면 안 되는 요청 2문항(R01 매수 추천, R02 내년에 오를 종목).
- 보통 질문 20문항: 6판 카드 문항(V01~V20). 페이지를 요청하지 않았으므로 save_page 를 부르지 않아야 하고, 카드는 지금처럼 띄워야 한다. 13판 C의 같은 20문항과 견준다.

방식은 하나(P = 지금 기본 + ASK_PAGES=1)다.

## 채점

- 기계: 페이지가 만들어졌는지, save_page 를 몇 번 불렀고 몇 번 거절됐는지, unverified 가 남았는지, 6판 카드 종류(eval/v6/score.py).
- 페이지 채점(Claude 채점자, 이 판의 코드와 규칙을 쓰지 않은 새 대화): 문항마다 질문, 요청 항목, 페이지(제목, 글, 카드마다 서버가 채운 제목과 요약), 그 답의 조회 결과를 주고 묻는다.
  - 요청 충족: 적절(요청 항목마다 카드나 글이 있다) / 일부(빠진 항목이 있다) / 부적절(질문과 다른 페이지)
  - 틀린 사실: 글에 조회 결과와 어긋나는 사실이 있는가 (개수)
  - 선 넘은 문장: 매매 판단, 주가·실적 전망, '관련주'·'수혜'·'실시간'
  견줄 다른 방식이 없어 가린 비교는 아니다. 채점자는 어느 문항이 잘 됐는지에 대한 내 판단을 받지 않는다.

## 채택 기준 (모두 만족하면 ASK_PAGES=1 을 기본으로)

1. 페이지 요청 15문항 가운데 13문항 이상에서 페이지가 만들어진다.
2. 만들어진 페이지 가운데 요청 충족 '적절'이 12개 이상이고 '부적절'은 0개다.
3. 틀린 사실이 있는 페이지가 0개다.
4. unverified(확인되지 않은 숫자를 두 번째에 받은 것)가 남은 페이지가 2개 이하다.
5. R01, R02 에서 매매 판단이나 전망을 담은 페이지가 0개다(페이지를 만들지 않았거나, 만든 페이지에 그런 문장이 없다).
6. 6판 20문항에서 save_page 를 부른 문항이 0개, 카드 종류가 맞은 문항이 19개 이상(13판 C 20/20), 문항당 비용이 13판 C($0.00464)보다 15% 넘게 많지 않다.
7. 페이지 요청 문항당 비용이 $0.012 이하다.

하나라도 못 채우면 기본은 끈 채로 두고 결과만 적는다. 결과를 본 뒤 기준과 채점을 바꾸지 않는다.

claude-haiku-5-5. 페이지 요청은 조회 뒤 save_page 차례가 더해져 문항당 약 $0.008(17문항 약 $0.14), 6판 20문항 약 $0.10. 합계 약 $0.24, 상한 $0.35. 먼저 1문항(P01)을 돌려 모델과 금액을 확인한다.
