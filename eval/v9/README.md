# 평가 문항 9판 — 자본 변동과 배당을 맞게 답하는가

쓴 날짜: 2026-10-20

Agent가 두 가지 자료를 쓸 수 있게 된다.

- 자본 변동 결정 공시(OpenDART 주요사항보고서 주요정보): 유상증자결정(`piicDecsn`), 무상증자결정(`fricDecsn`), 감자결정(`crDecsn`), 전환사채(`cvbdIsDecsn`), 신주인수권부사채(`bdwtIsDecsn`), 교환사채(`exbdIsDecsn`) 발행결정, 자기주식 취득결정(`tsstkAqDecsn`), 자기주식 취득 신탁계약 체결결정(`tsstkAqTrctrCnsDecsn`), 자기주식 처분결정(`tsstkDpDecsn`). 2024-01-01 부터 모았다. 날짜는 접수일(`rcept_no` 앞 8자리)이다.
- 배당(사업보고서의 배당에 관한 사항, `alotMatter.json`): 2025 사업보고서의 당기·전기·전전기(2025·2024·2023 사업연도)의 주당 현금배당금(보통주/우선주), 현금배당금총액, (연결)현금배당성향, 현금배당수익률, (연결)주당순이익.

이 문항들은 세 가지를 잰다.

1. 값을 맞게 답하는가: 그 결정의 값을 쓰는가(같은 회사의 다른 결정, 다른 해의 값을 섞지 않는가), 기간을 맞게 자르는가, 백만원을 원으로 맞게 바꾸는가, 직접 취득과 신탁계약을 구분하는가.
2. 질문에 맞는 카드를 고르는가: 희석 이력(`dilution`), 주주 환원(`payout`). 값 몇 개로 끝나는 질문에는 카드를 띄우지 않는가.
3. 없는 데이터를 없다고 하는가: 전환사채의 실제 전환량, 자기주식의 실제 취득 결과와 소각, 분기배당 회차별 금액, 앞으로의 배당.

## 만든 방법

- 문항과 gold 는 Claude 서브에이전트가 기능 구현 전에, 기능 설명만 보고 DART 원자료 API 를 직접 불러 썼다. Agent의 지시문과 새 코드(`company_graph/agent.py`, `views.py`, 자본 변동·배당 모듈)는 읽지 않았다. 유료 API(Anthropic)는 쓰지 않았다.
- 조회 시점(`as_of`)은 모두 2026-10-16. 모든 값은 `rcept_no` 앞 8자리가 20261016 이하인 행에서만 계산했다(고른 회사들에는 그 뒤 접수가 없었다).
- 후보 찾기: 로컬 DB 의 상장사(corp_cls Y/K, 종목코드 있음) 2,652개를 기준으로 `list.json`(pblntf_ty=B, 3개월 창)을 훑고, 이름이 잘 알려진 29개 회사(KT 는 DB 표시 이름이 달라 빠짐)와 2026-10 감자 공시가 있는 4개 회사(STX, 프리티, 제일엠앤에스, 이브이첨단소재)에는 위 9개 결정 API(와 유무상증자 `pifricDecsn`)를 `bgn_de=20240101`, `end_de=20261020` 으로 한 번씩 불렀다. 배당은 14개 회사에 `alotMatter.json`(bsns_year=2025, reprt_code=11011)을 불렀다. 결정이 정정된 회사(SK하이닉스, 에코프로비엠, 카카오게임즈, 고려아연, 한화에어로스페이스, 셀트리온, 카카오, HLB, KB금융, 삼성전자, 기아, LG화학)는 회사별 `list.json` 으로 처음 공시와 정정 순서를 확인했다. 무료 DART API 만 썼다.
- 금액은 원 단위로 적었다. 배당 표의 백만원 값은 ×1,000,000 했다. 자금 조달 목적 금액은 `fdpp_*` 여섯 칸의 합이다.
- 각 값의 `rcept_no` 와 `formula` 에 쓴 행과 식을 적었다. 이름 값(증자 방식, 취득 목적, 교환 대상)은 답에 알아볼 수 있게 나오면 맞음으로 본다.
- 질문은 실제 사용자 말투로 쓰고 "카드", "시각화", "그래프" 같은 말은 넣지 않았다. `company` 에는 DB 표시 이름을 적었다(사용자가 'KT&G', '현대차'로 불러도 DB 에서는 케이티앤지, 현대자동차).
- `acceptable_kinds`: dilution 문항은 timeline, payout 문항은 financials(D17 은 무상증자가 있어 dilution 도). 값 질문과 없는 데이터 질문은 `expected_kinds` 가 비어 있어 카드를 띄우지 않아야 맞다.

## 채점 기준

- 값: 수는 같으면 맞음(원 단위 금액은 상대 오차 0.5% 이내, %는 ±0.01%p, 주식 수·건수는 정확히). 이름 값은 답에 그 이름이 나오면 맞음. 다른 결정·다른 해의 값을 그 값처럼 적으면 틀림. 값이 없으면 빠짐.
- 카드: 6~8판과 같음.
- 없는 데이터 문항: must_say 를 모두 밝히고, 지어낸 숫자가 없으면 맞음.
- 채택 기준: 값 항목의 85% 이상 맞음, 틀린 값이 있는 문항 1개 이하, 카드가 필요한 문항의 80% 이상 맞음, 카드가 필요 없는 문항에 띄운 것 2개 이하, 없는 데이터 문항 모두 맞음.

카드 채점(6~8판과 같음): 기대 kind 를 하나 이상 띄우고 나머지는 모두 `acceptable_kinds` 안이면 맞음. `expected_kinds` 가 빈 문항은 카드를 띄우지 않아야 맞음.

## 만들면서 알게 된 것

- 결정 API 는 결정마다 마지막 정정본 한 행만 돌려준다. 그래서 날짜(접수번호 앞 8자리)가 처음 결정일이 아니라 마지막 정정일이 된다. 예: SK하이닉스 유상증자 처음 2026-06-24 → 행은 2026-07-10, 에코프로비엠 유상증자 처음 2026-06-30 → 행은 2026-10-13, 카카오게임즈 전환사채는 이사회 결의 2026-03-24 → 행은 2026-05-29, 한화에어로스페이스 주주배정 유상증자 처음 2025-03-20 → 행은 2025-06-27. as_of 를 처음 결정일과 마지막 정정일 사이로 두면 그 결정이 통째로 안 보인다(옛 정정본 값은 API 로 받을 수 없다).
- 처음 규모와 정정 뒤 규모가 다르다: 한화에어로스페이스의 처음 '3.6조 원' 주주배정은 데이터에 없고 정정 뒤 값(2조 9,188억 원)과 따로 생긴 제3자배정(1조 3,000억 원)만 있다.
- 철회된 결정: 고려아연 2024-10-30 일반공모 유상증자는 철회됐고, API 에는 마지막 정정(20241114000001)이 신주 수·금액이 모두 '-' 인 빈 행으로 남는다. 철회 표시는 없다.
- 같은 날 여러 결정: 카카오게임즈 2026-05-29 에 유상증자와 전환사채 정정이 함께 접수됐다. 한화에어로스페이스 2025-04-18 에도 새 결정과 정정이 같은 날 세 건.
- 자기주식 소각이 감자결정으로 들어오는 경우: 카카오(3건), 삼성물산(2건), LG전자(1건)의 감자결정은 모두 `cr_mth` '자기주식 소각'이다. 거래소 공시인 일반 소각 결정은 없지만 자본금을 줄이는 소각은 이렇게 보인다. 비율이 0.00~1.0% 로 작다.
- 교환사채의 교환 대상이 자기주식이 아닌 경우: LG화학 교환사채는 자회사 LG에너지솔루션 주식과 교환한다(LG화학 주식 수는 안 늘어남). 카카오·에코프로 교환사채는 자기주식, 카카오게임즈는 크래프톤 주식.
- 해외 사채의 권면총액(`bd_fta`)은 원화 환산값이고 외화 금액은 `ovis_fta`, 환율은 `ovis_ster` 에 있다(LG화학 USD 10억 달러 × 1,394.50, 카카오 교환사채 USD 2억 1,220만 달러 × 1,380.60).
- 자기주식 직접 취득결정과 신탁계약 체결결정은 다른 공시다. KB금융은 둘 다 있고(취득결정 4건 2조 200억 원, 신탁 5건 2조 1,800억 원), 신한지주·하나금융지주·메리츠금융지주도 신탁이 있다. 메리츠금융지주는 취득결정 없이 신탁만 7건.
- 자기주식 처분결정은 주주 환원이 아니라 임직원 보상·임금협상 지급·주식매수선택권 교부가 대부분이다(기아, 셀트리온, SK하이닉스 12건).
- 배당 표의 주식 종류 칸: 셀트리온은 '보통주'가 아니라 '-', NAVER 는 우선주 대신 '종류주', 카카오는 둘째 줄이 '-'. 신한지주는 2023 우선주(525원)만 값이 있다.
- 사업보고서 정정본: 신한지주(2026-10-07), 하나금융지주(2026-08-14), KB금융(2026-06-19) 의 배당 표는 정정 사업보고서에서 온다. as_of 를 그 전으로 두면 원래 보고서의 값과 접수번호가 다를 수 있다(API 는 마지막 것만 준다).
- 배당성향은 표의 값을 쓴다. SK하이닉스 2025 는 표 4.90%, 배당총액/연결순이익으로 나누면 4.88%. 배당성향이 소수 둘째 자리까지인 회사(신한지주 25.06, 우리금융지주 31.96, 셀트리온 15.92)와 첫째 자리까지인 회사가 섞여 있다.
- 적자 해의 배당성향은 '-'(SK하이닉스 2023, 카카오 2023).
- 메리츠금융지주는 2025 현금배당금총액·주당배당금이 '-' 로 비어 있다(2024 1,350원, 2023 2,360원). 배당이 없었다고 단정할 근거로는 약해 문항에 쓰지 않았다.
- 감자 공시가 2026-10 에 몰려 있다(STX 99.14% 회생계획, 제일엠앤에스 95.24% 회생계획, 이브이첨단소재 90.00% 10:1, 프리티 66.67% 3:1). 회생계획 감자는 대주주 주식 전량 무상소각과 차등 병합이 섞여 `cr_mth` 가 긴 문장이고, 몇 주가 1주가 되는지는 이 문장 안에만 있다. 프리티는 같은 해 두 번째 감자이고 마지막 정정이 as_of 당일(2026-10-16) 접수다.
- `list.json` 을 회사 없이 부르면 3개월 창만 되고, 한 쪽 100건에 한 번 6초가량 걸려 3개월 창 하나(약 2,000건)에 몇 분이 걸렸다. 그래서 전 시장 훑기는 2026-10-01~2026-10-20 창의 결과만 썼고(감자 회사 4곳을 여기서 찾음), 나머지 창은 끝까지 받지 않고 멈췄다. 그 밖의 회사는 이름 아는 회사를 직접 불렀다.
- 배당 금액은 백만원 단위로 반올림돼 있어 원 단위 값의 끝자리는 0 이다.
